# 📈 Projeto de Análise de Dados

Este repositório reúne scripts e rotinas dedicados ao ciclo completo de **Análise de Dados**. O objetivo principal do projeto é transformar bases desestruturadas em relatórios visuais e estatísticos que auxiliem na solução de problemas práticos e na tomada de decisões estratégicas.

---

## 🎯 Etapas do Projeto

1. **Coleta e Carregamento de Dados:** Leitura e consolidação de fontes de dados (CSV, Excel, bases relacionais ou APIs).
2. **Tratamento e Limpeza (Data Cleaning):**
   * Remoção de inconsistências e registros duplicados.
   * Tratamento de dados faltantes ou nulos.
   * Padronização de tipos de variáveis (datas, numéricos, categóricos).
3. **Análise Exploratória de Dados (EDA):**
   * Cálculo de métricas estatísticas essenciais (média, mediana, desvio padrão).
   * Identificação de correlações, tendências e *outliers*.
4. **Visualização de Dados:**
   * Construção de gráficos interativos e estáticos para facilitar a interpretação dos resultados.

---

## 🛠️ Tecnologias Utilizadas

* **Python 3.14
* **Pandas**: Manipulação, limpeza e agregação de dados.
* **NumPy**: Operações estatísticas e computação numérica.
* **Matplotlib / Seaborn**: Criação de gráficos e visualização de dados.
* **Jupyter Notebook**: Ambiente interativo para documentação e análise passo a passo.
