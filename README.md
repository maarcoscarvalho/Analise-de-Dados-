# Programa de Dados

Projeto de análise de dados com clientes, funcionários e serviços prestados.

## Arquivos principais
- `primeiro.ipynb`: notebook com a análise exploratória e cálculos principais.
- `CadastroClientes.csv`: cadastro de clientes.
- `CadastroFuncionarios.csv`: cadastro de funcionários.
- `BaseServicosPrestados.xlsx`: base de serviços prestados.

## Objetivo
Analisar indicadores como folha salarial, faturamento, ticket médio, quantidade de contratos por área e percentual de funcionários envolvidos em contratos.
